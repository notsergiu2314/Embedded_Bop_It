# Bop-It: two-player reaction game

A two-player "Bop It" style reaction game for the **NUCLEO-F401RE** (STM32F401RE, Cortex-M4),
written in C on **FreeRTOS** (CMSIS-RTOS V2 API) with STM32CubeMX / STM32CubeIDE.

The microcontroller picks a random action for each player and lights the matching LED. The player
has to react in time with the right input: press the **button**, flip the **switch** or turn the
**potentiometer**. Wrong inputs, late inputs and inputs before the cue are detected, and the
reaction times (1 microsecond resolution) decide who was faster. Scores (0-9) are shown on one
7-segment display per player, and a buzzer gives audio feedback.

## Hardware

* NUCLEO-F401RE
* Per player: 1 push button, 1 slide switch, 1 potentiometer and 1 cue LED for each of them
* 2 x 7-segment display, driven by 2 daisy-chained 74HC595 shift registers (one per player)
* 1 passive buzzer

## Getting started

1. Clone the repository.
2. In STM32CubeIDE: **File -> Import -> General -> Existing Projects into Workspace**, select the
   cloned folder (do not tick *Copy projects into workspace*).
3. If the build cannot find `board.h`: **Project -> Properties -> C/C++ General -> Paths and
   Symbols** and add `App` as a source folder (Source Location tab) and `App/Inc` as an include
   directory (Includes tab, GNU C).
4. Build, connect the Nucleo with USB and run. Debug messages are sent over the ST-LINK virtual
   COM port at 115200 baud.

## Working together

* Only one person edits `bopit.ioc` at a time. It merges badly, so agree on pin changes first.
* Put our code in `App/`. In generated files, write only between `USER CODE BEGIN/END`.
* Work on a branch and open a pull request into `main`.
